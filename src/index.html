ABOUT THE ATLAS

Good food, good stories.

Dim Sum Atlas reads the public Hong Kong dim-sum catalog and caches selected public release images in app data, never in this repository. Every invented origin and fact is marked as fictional catalog lore, so playful storytelling never pretends to be history.
