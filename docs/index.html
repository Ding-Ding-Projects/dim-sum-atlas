PUBLIC TEA-HOUSE CATALOGUE

Dim Sum Atlas

A Material 3 Windows desktop atlas for the public Hong Kong dim-sum catalog. Browse every record, inspect ingredients and allergens, save favorites, search with a bounded JavaScript regex builder, and export your table.

Download the latest Windows build

Public source

Dish names and metadata come from Ding-Ding-Projects/dim-sum-photos. Images stay in the app-data cache and are never copied into this repository.

Truthful lore

Origin stories and catalog facts are deterministic fictional lore. The app labels them so playful writing never pretends to be history.

Accessibility and safety

Keyboard-operable cards and tabs, visible focus, non-blocking notifications, local exports, and a two-key destructive-action gate are part of the app surface.
